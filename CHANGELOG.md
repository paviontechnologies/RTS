# Changelog

All notable changes to Pavion RTS will be documented in this file.

## [2.4.0] - 2026-11-14
### Added
- Enterprise Polyglot Multi-Tier Architecture (TypeScript, Python, Go, SQL, Shell).
- Autonomous AI Recruitment Agents (`agents/`).
- Curated US Staffing Job Descriptions library across Cloud, Data, ERP, and Full Stack (`jds/`).
- Standard ATS Resume Templates and Structured Interview Question Kits (`templates/`, `interview-prep/`).
- High-Performance Candidate Search Indexer in Go (`tools/indexer/`).
- Batch resume ingestion and compliance auditors (`batch/`).
- Multi-job CI/CD pipeline covering Node.js, Python, Docker, and Shell.

## [2.0.0] - 2026-11-03
### Added
- 9 Specialized Enterprise Recruitment Modules (Talent Pools, Screening, Interview Kits, Offers, Onboarding, Compliance, Communications, Redeployment, Vendors).
- PostgreSQL 18 Multi-Schema Architecture (8 domain schemas, 79 relational tables).
