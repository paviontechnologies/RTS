# Job Description: Senior AWS Solutions Architect

- **Requisition ID**: REQ-AWS-001
- **Domain**: Cloud & Infrastructure
- **Client**: Financial Services Enterprise (via Pavion Technologies)
- **Location**: Dallas, TX (Hybrid: 2 days onsite / 3 days remote)
- **Duration**: 12+ Months Contract-to-Hire
- **Pay Rate**: $95.00 - $115.00 / hr W2 / C2C
- **Work Authorization**: US Citizen, Green Card, or H-1B Transfer

## Role Overview
We are seeking an experienced **Senior AWS Solutions Architect** to lead the migration and modernization of core banking microservices onto AWS cloud infrastructure. You will collaborate with engineering squads to define Well-Architected frameworks, implement IAM security guardrails, and automate Terraform CI/CD pipelines.

## Key Responsibilities
- Architect high-availability, fault-tolerant infrastructure utilizing Amazon EKS, ECS Fargate, Lambda, SQS, and RDS PostgreSQL.
- Lead Infrastructure as Code (IaC) governance using modular Terraform and AWS CloudFormation.
- Drive cost optimization, security hardening, and observability using CloudWatch, Prometheus, and Datadog.

## Required Qualifications
- 8+ years in enterprise IT infrastructure with 5+ years dedicated to AWS architecture.
- AWS Certified Solutions Architect - Professional.
- Deep hands-on experience with Kubernetes, Docker, and service mesh (Istio).
