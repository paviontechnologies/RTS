# ATS Operations Skill

This skill equips agents with end-to-end recruitment lifecycle operations:
1. Parse unstructured resumes into normalized JSON schemas.
2. Calculate weighted candidate-job fit scores.
3. Generate compliant Right-to-Represent (RTR) confirmation agreements.
4. Screen candidate submissions against visa, relocation, and rate knockout rules.
